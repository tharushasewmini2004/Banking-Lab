# SQL Intern Assignment Workbook

5-day SQL Server workbook using a banking schema (Customers, Accounts, Transactions).

- **Day 1:** Database foundations, SELECT, filtering, aggregation
- **Day 2:** JOINs and relationship reasoning
- **Day 3:** Subqueries, CTEs, set operators, window functions
- **Day 4:** Constraints, atomic transfers, indexes, views, procedures
- **Day 5:** Performance tuning, reporting diagnosis, final validated report

Tools: SQL Server, SSMS
